# Velum UI

Режим Operate. Визуальный эталон — Arena `d8049c3`; текущая реализация Flutter.

Базовые цвета: фон #0b0616, приподнятая поверхность #130a24, карточка rgba(26,14,49,.78), основной лаймовый #b8ff14, фиолетовый #a855f7, светлый фиолетовый #c084fc. Граница карточки rgba(168,85,247,.22). Приложение использует тёмные палитры; тема меняется через пять вариантов оформления.

Шапка48px, центральная колонка подключения540px/списков и настроек560px; внутренние отступы16px. Нижняя плавающая панель шириной440px, отступ16px снизу; до640px иконка над текстом. Карточки24px radius, строки серверов16px radius, поля16px radius. Размеры orb192px/центральной кнопки144px. Шрифт Noto Sans, технические значения Noto Sans Mono; Lucide SVG. Фон: полупрозрачные узоры из эталона и мягкие фиолетовые градиенты.

Существующая клиентская модель и Go-служба сохраняются. Статус процесса не считается подтверждённой доступностью; трафик не моделируется. Неподдержанные функции отключены с пояснением. Состояния: пусто, загружено, занят, ошибка, отключено, ядро работает, соединение проверено. Визуальные проверки выполняются с отдельными тестовыми данными, без пользовательских секретов.

Подробности и воспроизведение снимков: docs/arena-flutter.md.
