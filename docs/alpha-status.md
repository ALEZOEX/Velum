## Открытые ограничения

- **F1 — Windows Service:** безопасность ACL остаётся открытым замечанием.
  Этот перенос не подтверждает безопасность прав доступа службы и её файлов.
- **F2 — Linux TUN:** проверка занятости ресурсов не устраняет гонку после
  preflight. После SIGKILL могут оставаться policy rules. Возможны отказ
  повторного запуска и необходимость отдельной диагностики. Подробности:
  [владение маршрутизацией Linux TUN](linux-tun-ownership.md).
- **F9 — трей:** определение фактической доступности трея недостаточно надёжно;
  постоянная доступность возможности восстановить скрытое окно не гарантирована.
  Подробности: [жизненный цикл окна](window-lifecycle.md).
- **F10–F15:** оставшиеся замечания первоначального аудита сохраняют открытый
  статус. В рамках переноса их устранение не проверялось и не выполнялось.

Windows runtime и полный Linux TUN в основной системе не подтверждены.
Кросс-компиляция, mock-тесты и исторические проверки в изолированных namespaces
не заменяют эти проверки. Android пока не поддерживается.
