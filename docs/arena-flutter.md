# Интерфейс Arena во Flutter

Эталон: ветка `arena/59f5a804-velum`, commit `d8049c3`.

Перенесены компоновка и размеры экранов подключения, серверов, настроек и маршрутизации; верхняя панель, нижние вкладки, карточки провайдера, протокольные метки, избранное, фоновые узоры и пять палитр. Диалоги импорта, параметров/QR сервера, журнала и редактора правил реализованы отдельными Flutter-виджетами. Lucide SVG перенесены из зависимости эталона с сохранением лицензии. Текст использует включённые Noto Sans и Noto Sans Mono.

Действия используют `VelumClient` и существующую Go-службу sing-box. Импорт QR из файла на Linux использует `zbarimg`; ссылка перед добавлением остаётся доступна для просмотра и подтверждения. Оформление и сообщение `announce` подписки сохраняются вместе с остальными данными, включая резервные копии.

## Воспроизводимые снимки

```
cd app
VELUM_CAPTURE_DIR=/tmp/velum-exact flutter test test/arena_visual_test.dart
flutter build linux --release
cd ..
python3 scripts/preview.py --output /tmp/velum-native.png
```

Тесты отрисовывают пять основных состояний на 480×760 и 980×760 с документальными адресами 192.0.2.0/24. Native preview запускается в отдельной сессии D-Bus/Xvfb с временным каталогом `VELUM_CONFIG_DIR`. Пользовательские подписки и учётные данные не попадают в снимки.

## Различия, связанные с функциональностью

Это нативный Flutter-интерфейс существующего Linux-клиента. Вместо Xray JSON показываются данные профиля и сохранённые настройки sing-box; нет выдуманных IP, скоростей или подтверждения безопасности. Kill switch, crypt1 и географические пресеты, которые ещё не поддержаны службой, отключены с пояснением. Выбор текущего провайдера, квоты, даты, имена и статусы зависят от настоящих данных. Диалог параметров сервера выдаёт QR с секретами только по явному действию пользователя. Пиксельная идентичность разных движков рендеринга не гарантируется.

Linux-окно использует собственную панель управления с GTK-обработчиками сворачивания, разворачивания, перемещения и закрытия. Windows runner и управление его окном в этой итерации не проверены.
